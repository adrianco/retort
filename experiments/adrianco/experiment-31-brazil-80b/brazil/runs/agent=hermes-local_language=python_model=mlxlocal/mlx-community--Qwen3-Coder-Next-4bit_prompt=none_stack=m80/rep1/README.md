# Brazilian Soccer MCP Server

## Overview

This project implements an MCP (Model Context Protocol) server for Brazilian soccer data. The server enables natural language queries about players, teams, matches, and competitions using pre-downloaded Kaggle datasets.

## Features

- **Match Queries**: Search matches by team, date, competition, and season
- **Team Queries**: Get team statistics, win/loss records, head-to-head comparisons
- **Player Queries**: Search players by name, nationality, club, and position
- **Competition Queries**: Calculate standings, get cup brackets, analyze competition summaries
- **Statistical Analysis**: Calculate averages, trends, and performance metrics

## Data Sources

All datasets are pre-downloaded and included in `data/kaggle/`:

| Dataset | Matches | Description |
|---------|---------|-------------|
| Brasileirão Serie A | 4,180 | Brazilian top-tier league matches |
| Copa do Brasil | 1,337 | Brazilian cup matches |
| Copa Libertadores | 1,255 | South American club cup matches |
| BR-Football-Dataset | 10,296 | Extended match statistics |
| Historical Brasileirão | 6,886 | 2003-2019 league matches |
| FIFA Players | 18,207 | Player ratings and attributes |

## Usage

### Basic Example

```python
from brazilian_soccer_mcp import create_app
from brazilian_soccer_mcp.data_loader import get_data_loader
from brazilian_soccer_mcp.match_queries import MatchQueryHandler

# Initialize
loader = get_data_loader()
match_handler = MatchQueryHandler(loader)

# Find Flamengo matches in 2023
matches = match_handler.find_matches_by_team("Flamengo", season=2023)
print(f"Found {len(matches)} matches")

# Get head-to-head between Flamengo and Fluminense
h2h = match_handler.find_match_by_teams("Flamengo", "Fluminense", limit=10)
print(f"Found {len(h2h)} head-to-head matches")
```

### Query Examples

```python
# Match queries
matches = match_handler.find_matches_by_team("Palmeiras", season=2023)
h2h = match_handler.find_match_by_teams("Flamengo", "Fluminense")

# Team queries
stats = team_handler.get_team_statistics("Palmeiras", season=2023)
h2h = team_handler.get_head_to_head("Flamengo", "Fluminense")

# Player queries
player = player_handler.get_player_by_name("Neymar Jr")
brazilian_top = player_handler.get_brazilian_top_rated(limit=5)

# Competition queries
standings = competition_handler.calculate_standings(2019, "Brasileirão")
champion = competition_handler.get_champion(2019, "Brasileirão")
```

### Running the MCP Server

```python
from brazilian_soccer_mcp import create_app

app = create_app()
app.run(host="0.0.0.0", port=8000)
```

- **Statistical Analysis**: Averages, trends, big wins
