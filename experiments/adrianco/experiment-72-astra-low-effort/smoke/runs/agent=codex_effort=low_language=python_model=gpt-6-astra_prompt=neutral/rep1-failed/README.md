# Book collection API

A Python Flask REST service using a persistent SQLite database. Requires Python 3.10+.

## Setup and run

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

The service listens on http://127.0.0.1:5000. Set `PORT` to change the port.
Set `BOOKS_DATABASE` to a SQLite file path (default: `books.db` in the working
directory). Its parent directory must exist. The schema is created automatically.
The bundled server is intended for local development.

## Endpoints

| Method | Path | Success |
| --- | --- | --- |
| GET | `/health` | 200, `{"status":"ok"}` |
| POST | `/books` | 201, created book; `Location` header |
| GET | `/books` | 200, book array ordered by ID |
| GET | `/books?author=Alice` | 200, exact, case-sensitive author match |
| GET | `/books/{id}` | 200, book |
| PUT | `/books/{id}` | 200, replaced book |
| DELETE | `/books/{id}` | 200, JSON deletion confirmation |

POST and PUT require a JSON object with nonblank string `title` and `author`.
Optional `year` is an integer from 1 through 9999 or null; `isbn` is a nonblank
string or null. ISBN format and uniqueness are not enforced. Strings are trimmed.
Unknown fields are rejected. IDs are generated by the database. PUT replaces all
editable fields; omitted year and ISBN become null.

Invalid input returns 400, a non-JSON content type returns 415, missing books
return 404, and unsupported methods return 405. Errors have a JSON `error` field.

```sh
curl -i http://127.0.0.1:5000/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune","author":"Frank Herbert","year":1965,"isbn":"9780441172719"}'
curl 'http://127.0.0.1:5000/books?author=Frank%20Herbert'
```

## Tests

```sh
python -m pytest -q
python -m compileall -q app.py test_app.py
```

Tests use isolated temporary SQLite files and cover the full CRUD lifecycle,
author filtering, validation, JSON errors, health, and persistence across app instances.
