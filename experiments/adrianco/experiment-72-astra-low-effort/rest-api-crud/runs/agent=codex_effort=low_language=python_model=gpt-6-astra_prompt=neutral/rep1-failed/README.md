# Book collection API

A Python 3.9+ Flask service using SQLite. The database schema is created automatically.

## Setup and run

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

The service listens at `http://127.0.0.1:5000`. Data persists in `books.sqlite3`
in the working directory. Set `BOOKS_DATABASE` to a different database file path
before starting if desired (its parent directory must exist).
The built-in server is intended for local development.

## Endpoints

| Method | Path | Success response |
| --- | --- | --- |
| POST | `/books` | 201, created book and Location header |
| GET | `/books` | 200, array of books ordered by ID |
| GET | `/books?author=Frank%20Herbert` | 200, exact, case-sensitive author matches |
| GET | `/books/{id}` | 200, book |
| PUT | `/books/{id}` | 200, replaced book |
| DELETE | `/books/{id}` | 200, `{"deleted": 1}` |
| GET | `/health` | 200, `{"status": "ok"}` after checking database connectivity |

POST and PUT require a JSON object with nonblank string `title` and `author`;
surrounding whitespace is trimmed. Optional `year` is an integer or null and
`isbn` is a string or null (preserving leading zeros). PUT replaces all four
fields; omitted optional fields become null. IDs are generated by SQLite.
Unknown input fields are ignored. Duplicate ISBNs are allowed.

```sh
curl -i http://127.0.0.1:5000/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune","author":"Frank Herbert","year":1965,"isbn":"0441172717"}'
curl http://127.0.0.1:5000/books
```

Errors return JSON of the form `{"error": "message"}`: 400 for invalid JSON
or field values, 415 for requests without JSON content type, 404 for missing
books/routes, and 405 for unsupported methods.

## Tests

```sh
python -m unittest discover -v
python -m compileall -q app.py test_app.py
```

Tests use isolated temporary databases and cover CRUD, filters, validation,
failed update preservation, HTTP errors, health, and persistence after reopening.
