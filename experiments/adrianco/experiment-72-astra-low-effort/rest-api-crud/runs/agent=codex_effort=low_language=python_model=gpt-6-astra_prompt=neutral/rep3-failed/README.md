# Book Collection API

Python 3.10+ REST service using Flask and SQLite. Flask was selected because the task does not specify a framework. All responses use JSON except successful DELETE responses, which have no body.

## Setup and run

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

The service listens at http://127.0.0.1:5000. The database and schema are created automatically. By default, data persists in `books.sqlite3` in the working directory. Set `BOOKS_DATABASE` to another SQLite file path (its parent directory must exist). The Flask development server is for local use.

Alternatively: `flask --app 'app:create_app()' run`.

## API

| Method | Path | Result |
| --- | --- | --- |
| POST | `/books` | Create a book; 201 with book and Location header |
| GET | `/books` | 200 with array ordered by ID; optional exact, case-sensitive `?author=` filter |
| GET | `/books/{id}` | 200 with book, or 404 |
| PUT | `/books/{id}` | Replace book fields; 200 with updated book, or 404 |
| DELETE | `/books/{id}` | 204 with empty body, or 404 |
| GET | `/health` | 200 with `{"status":"ok"}` after a database connectivity check |

POST and PUT require a JSON object with nonblank string `title` and `author`. `year` is optional (a signed 64-bit integer or null); `isbn` is optional (a nonblank string or null). ISBN is stored as supplied, without checksum or uniqueness enforcement. String fields are trimmed. Unknown fields are rejected. PUT requires title and author and clears omitted optional fields to null. IDs are generated by SQLite.

Invalid input or malformed JSON returns 400; non-JSON content types return 415. Errors have the shape `{"error":"description"}`.

```sh
curl -i -X POST http://127.0.0.1:5000/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"The Left Hand of Darkness","author":"Ursula K. Le Guin","year":1969,"isbn":"9780441478125"}'
curl 'http://127.0.0.1:5000/books?author=Ursula%20K.%20Le%20Guin'
```

## Tests

```sh
python -m unittest discover -v
python -m compileall -q app.py test_app.py
```

Tests use independent temporary SQLite files and Flask's HTTP test client. They cover CRUD, author filtering, input errors, missing records, persistence across app instances, failed-update preservation, optional fields, and health.
