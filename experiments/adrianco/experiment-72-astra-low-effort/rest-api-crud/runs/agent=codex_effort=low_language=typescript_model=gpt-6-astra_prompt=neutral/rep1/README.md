# Book collection API

TypeScript REST service using Express 5 and Node's built-in SQLite database.
Requires Node.js **22.13 or newer** and npm. Some Node versions print an experimental SQLite warning.

## Setup and run

```sh
npm ci
npm run build
npm start
```

The service listens on port `3000` and stores data in `books.sqlite` in the working directory. Configure either with environment variables:

```sh
PORT=8080 DB_PATH=./collection.sqlite npm start
```

The database file and schema are created automatically; the containing directory must already exist. Data survives restarts. Set `DB_PATH=:memory:` for temporary storage.

## API

All responses, including errors and successful deletion, use JSON.

| Method | Path | Success |
| --- | --- | --- |
| GET | `/health` | 200, `{"status":"ok"}` after a database query |
| POST | `/books` | 201, created book; `Location` header |
| GET | `/books` | 200, array ordered by ID |
| GET | `/books?author=Ursula%20K.%20Le%20Guin` | 200, exact case-sensitive author match |
| GET | `/books/:id` | 200, book |
| PUT | `/books/:id` | 200, replaced book |
| DELETE | `/books/:id` | 200, `{"message":"Book deleted"}` |

POST and PUT accept JSON objects with required non-blank string `title` and `author`. Strings are trimmed. Optional `year` must be a safe integer or null; optional `isbn` must be a non-blank string or null. ISBN formatting/checksums are not enforced. PUT is a full replacement: title and author remain required, and omitted optional fields become null. Unknown fields are ignored; IDs are generated by the database and cannot be changed.

Invalid input, malformed JSON, and invalid IDs return 400. Missing books and routes return 404. Bodies over 100 KB return 413. Errors have the form `{"error":"message"}`. IDs must be positive safe integers. The service does not impose ISBN uniqueness.

```sh
curl -i http://localhost:3000/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"The Left Hand of Darkness","author":"Ursula K. Le Guin","year":1969,"isbn":"9780441478125"}'
curl http://localhost:3000/books/1
curl 'http://localhost:3000/books?author=Ursula%20K.%20Le%20Guin'
curl -X PUT http://localhost:3000/books/1 \
  -H 'Content-Type: application/json' \
  -d '{"title":"A Wizard of Earthsea","author":"Ursula K. Le Guin","year":1968}'
curl -X DELETE http://localhost:3000/books/1
```

## Tests

```sh
npm test
```

This compiles the TypeScript and runs six tests with Node's test runner. HTTP integration tests use in-memory HTTP connections and isolated in-memory databases, so they also run in environments that prohibit listening on TCP ports. The persistence test opens and closes a temporary SQLite file to verify creation, updates, and deletion survive database reopening.
