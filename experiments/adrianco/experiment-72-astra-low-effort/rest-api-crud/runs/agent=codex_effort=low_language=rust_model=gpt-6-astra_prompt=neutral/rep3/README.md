# Book collection API

Rust REST service using Axum and embedded SQLite. SQLite is bundled; no database server or separate SQLite installation is needed.

## Setup and run

Install a current stable Rust toolchain (including Cargo), then run from this directory:

```sh
cargo build --locked
cargo run --locked
```

The service listens at `http://127.0.0.1:3000`. It creates `books.db` in the current directory and preserves books across restarts. Override settings with environment variables:

```sh
DATABASE_PATH=/tmp/collection.db BIND_ADDR=0.0.0.0:8080 cargo run --locked
```

The database's parent directory must exist. Ctrl-C gracefully shuts down the server. Database operations run on blocking workers, serialized through a shared SQLite connection.

## API

All response bodies are JSON. Errors have the form `{"error":"message"}`.

| Method | Path | Success |
|---|---|---|
| POST | `/books` | 201, created book and `Location` header |
| GET | `/books` | 200, array ordered by ID |
| GET | `/books?author=Frank%20Herbert` | 200, exact case-sensitive author matches |
| GET | `/books/{id}` | 200, book |
| PUT | `/books/{id}` | 200, replaced book |
| DELETE | `/books/{id}` | 200, `{"deleted":id}` |
| GET | `/health` | 200, `{"status":"ok"}` after checking database connectivity |

POST and PUT accept `title`, `author`, `year`, and `isbn`. Title and author must be nonblank strings; surrounding whitespace is trimmed. Year is an optional signed 32-bit integer and ISBN is an optional string; omitted or null values are stored as null. ISBN format and uniqueness are not restricted. PUT replaces all editable fields, so omitted optional fields become null. IDs are generated by SQLite and must be positive integers in requests.

Invalid JSON, field types, required fields, or IDs return 400. Missing books or routes return 404; unsupported methods return 405. Database failures return 500 without exposing database details.

```sh
curl -i -X POST http://127.0.0.1:3000/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune","author":"Frank Herbert","year":1965,"isbn":"9780441172719"}'
curl 'http://127.0.0.1:3000/books?author=Frank%20Herbert'
curl http://127.0.0.1:3000/books/1
curl -X PUT http://127.0.0.1:3000/books/1 \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune (updated)","author":"Frank Herbert","year":1965}'
curl -X DELETE http://127.0.0.1:3000/books/1
curl http://127.0.0.1:3000/health
```

## Verification

```sh
cargo test --locked
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
```

Five integration-style tests exercise the actual router with isolated databases: CRUD, author filtering (including SQL-like input), validation with unchanged data, missing and malformed IDs, health checks, and persistence after reopening a file database.
