# Brazilian Soccer MCP with spec and basic data sets

## Running the server

```sh
go build -o brazilian-soccer-mcp .
./brazilian-soccer-mcp
```

It loads all six bundled CSV files from `data/kaggle`; set `SOCCER_DATA_DIR` to
choose another directory. MCP tools: `search_matches`, `team_statistics`,
`head_to_head`, `search_players`, `standings`, and `competition_statistics`.
