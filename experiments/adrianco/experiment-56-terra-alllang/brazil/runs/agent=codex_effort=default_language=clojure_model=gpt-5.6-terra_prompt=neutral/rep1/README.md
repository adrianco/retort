# Brazilian Soccer MCP with spec and basic data sets

## Server

This repository includes a dependency-free Clojure stdio MCP server. It loads every supplied CSV, normalizes team names and dates, and exposes match, team, player, standings, and aggregate-statistics tools.

Run the server with: clojure -M -m brazilian-soccer-mcp.core

Run the BDD-style behavior tests with: clojure -M:test
