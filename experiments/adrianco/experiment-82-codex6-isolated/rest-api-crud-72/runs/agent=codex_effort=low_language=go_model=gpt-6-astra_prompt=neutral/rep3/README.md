# Book collection API

A Go REST service using the standard `net/http` library and SQLite. The database and schema are created automatically at startup.

## Setup and run

Requires Go 1.22+ and a C compiler (SQLite's Go driver uses CGO). On macOS, install the Xcode command line tools; on Linux, install GCC or Clang.

```sh
go mod download
go build -o bookcollection .
./bookcollection
```

The default address is `:8080`, and data is stored in `books.db` in the working directory. Configure either with environment variables:

```sh
ADDR=127.0.0.1:9000 DB_PATH=./collection.db ./bookcollection
```

## API

| Method | Path | Success |
| --- | --- | --- |
| POST | `/books` | 201, created book and `Location` header |
| GET | `/books` | 200, array ordered by ID (empty array when no matches) |
| GET | `/books?author=Frank%20Herbert` | 200, exact, case-sensitive author matches |
| GET | `/books/{id}` | 200, book |
| PUT | `/books/{id}` | 200, replaced book |
| DELETE | `/books/{id}` | 204, empty body |
| GET | `/health` | 200, `{"status":"ok"}`; 503 if database unavailable |

Create and update accept a JSON object with `title`, `author`, `year`, and `isbn`. Title and author must be nonempty strings after trimming whitespace. Year is an optional integer (defaults to 0); ISBN is an optional string (defaults to empty). PUT replaces all fields, so omitted optional fields reset to their defaults. IDs are generated by the database. ISBN uniqueness and format are not restricted.

```sh
curl -i -X POST http://localhost:8080/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune","author":"Frank Herbert","year":1965,"isbn":"9780441172719"}'
curl 'http://localhost:8080/books?author=Frank%20Herbert'
curl http://localhost:8080/books/1
curl -X PUT http://localhost:8080/books/1 \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune Messiah","author":"Frank Herbert","year":1969}'
curl -i -X DELETE http://localhost:8080/books/1
```

Responses with bodies are JSON. Errors have the form `{"error":"message"}`. Invalid input, unknown JSON fields, malformed JSON, and invalid IDs return 400; missing books/routes return 404; unsupported methods return 405 with an `Allow` header; bodies over 1 MiB return 413; database failures return 500. The service handles SIGINT/SIGTERM with graceful shutdown.

## Tests

```sh
go test ./...
go test -race ./...
go vet ./...
```

Tests use isolated temporary SQLite databases and cover CRUD, filtering, validation, routing, health, and persistence across database reopens.
