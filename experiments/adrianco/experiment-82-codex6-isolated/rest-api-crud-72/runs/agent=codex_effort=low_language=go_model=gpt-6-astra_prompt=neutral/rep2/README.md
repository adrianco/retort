# Book collection API

A Go REST service using the standard `net/http` library and a pure-Go SQLite driver. Requires Go 1.23 or newer; no C compiler or separate database server is needed.

## Run

```sh
go mod download
go run .
```

The service listens on `:8080` and creates `books.db` in the current directory. Configure these using `ADDR` and `DB_PATH`:

```sh
ADDR=127.0.0.1:8081 DB_PATH=./collection.db go run .
```

The database directory must already exist. Books persist across restarts.

## API

All request and response bodies are JSON, except successful DELETE responses, which have no body. Errors have the form `{"error":"message"}`.

| Method | Path | Success |
| --- | --- | --- |
| POST | `/books` | 201, created book and `Location` header |
| GET | `/books` | 200, array ordered by ID; empty collection is `[]` |
| GET | `/books?author=Frank%20Herbert` | 200, exact, case-sensitive author matches |
| GET | `/books/{id}` | 200, book |
| PUT | `/books/{id}` | 200, replaced book |
| DELETE | `/books/{id}` | 204, no body |
| GET | `/health` | 200, `{"status":"ok"}`; 503 if database is unavailable |

POST and PUT accept `title` (string), `author` (string), `year` (integer), and `isbn` (string). Title and author are required, trimmed, and must not be blank. Year and ISBN default to `0` and `""` when omitted. PUT fully replaces the editable fields and requires title and author. IDs are generated by the server and must be positive integers in paths. Unknown JSON fields, malformed input, and invalid IDs return 400; missing books return 404; unsupported methods return 405. Request bodies are limited to 1 MiB (413 when exceeded). ISBN is stored as supplied, with no uniqueness or format restriction.

```sh
curl -i http://localhost:8080/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune","author":"Frank Herbert","year":1965,"isbn":"9780441172719"}'
curl 'http://localhost:8080/books?author=Frank%20Herbert'
curl http://localhost:8080/books/1
curl -X PUT http://localhost:8080/books/1 \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune","author":"Frank Herbert","year":1965,"isbn":"updated"}'
curl -i -X DELETE http://localhost:8080/books/1
curl http://localhost:8080/health
```

## Build and test

```sh
go build -o bookcollection .
go test ./...
go test -race ./...
```

Tests use isolated temporary SQLite files and cover CRUD, author filtering, validation, error statuses, health, and persistence across database reopening.
