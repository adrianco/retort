# Book collection API

A Python 3.10+ REST service using standard-library WSGI and SQLite. No external dependencies or installation are required. No framework was specified by the task (`stack.json` lists `unknown`).

Run from this directory:

```sh
python3 app.py --host 127.0.0.1 --port 8000
```

The database is created automatically at `books.sqlite3`. Use `--database /path/to/books.sqlite3` or the `BOOKS_DB` environment variable to choose another file. Its parent directory must exist. Data persists across restarts. The bundled WSGI server is intended for local use; a production WSGI server can load `app:create_app()`.

| Method | Path | Result |
| --- | --- | --- |
| POST | `/books` | Create a book; 201, book JSON and Location header |
| GET | `/books` | 200, JSON array ordered by ID |
| GET | `/books?author=Frank%20Herbert` | Exact, case-sensitive author filter |
| GET | `/books/{id}` | 200, book JSON; 404 if absent |
| PUT | `/books/{id}` | Replace book fields; 200, updated book JSON |
| DELETE | `/books/{id}` | 204, empty body; 404 if absent |
| GET | `/health` | 200, `{"status":"ok"}` after a database query |

POST and PUT require `Content-Type: application/json` and an object containing nonblank string `title` and `author`. Optional `year` is an integer from 1 through 9999 or null; optional `isbn` is a nonblank string or null. ISBN format/checksum validation is not imposed. Strings are trimmed. PUT requires both title and author, and omitted optional fields become null. IDs are generated by the database; unknown input fields are rejected.

Invalid inputs return 400, unsupported content types 415, bodies larger than 1 MiB 413, unknown routes/books 404, and unsupported methods 405 with an Allow header. Errors have a JSON `error` field. DELETE's 204 response has no body, as required by HTTP.

```sh
curl -i http://127.0.0.1:8000/books \
  -H 'Content-Type: application/json' \
  -d '{"title":"Dune","author":"Frank Herbert","year":1965,"isbn":"9780441172719"}'
curl 'http://127.0.0.1:8000/books?author=Frank%20Herbert'
```

Run the integration tests and syntax compilation:

```sh
python3 -m unittest -v
python3 -m py_compile app.py test_app.py
```

Tests use isolated temporary databases and cover CRUD, filtering, validation, error responses, persistence, and the health endpoint through WSGI and over a real HTTP connection. The HTTP test skips when the environment prohibits listening sockets.
