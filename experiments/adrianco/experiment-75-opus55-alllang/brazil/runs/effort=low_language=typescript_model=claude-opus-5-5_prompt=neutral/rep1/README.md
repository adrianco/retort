## MCP server (TypeScript)

```bash
npm install && npm run build && npm test
node dist/server.js   # stdio MCP server
```

Tools: `search_matches`, `head_to_head`, `team_stats`, `standings`, `competition_stats`, `biggest_wins`,
`best_records`, `team_competitions`, `derbies`, `search_players`, `get_player`, `brazilian_club_players`,
`team_profile`, `dataset_info`. Source lives in `src/`, BDD-style tests in `tests/`.
